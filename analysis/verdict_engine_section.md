R130 看到 `Cybersole.Core` 有 22 个 embedded resource，R131–133 处理了 4 个 locale，
这一轮把剩下的 18 个里能切的 14 个切了出来。

**`EmptySolver.html` 是个陷阱**：它的内容以 `data:text/html;base64,` 开头，不是 `<!DOCTYPE html>`，
所以按文档开头搜的循环漏掉了它。解开之后是一个带 **Test reCAPTCHA / Test hCaptcha** 两个按钮的测试页。

### 四个脚本

| 文件 | 大小 | 行数 | 注释行 |
|---|---|---|---|
| `castle.js` | 328,998 | 7,083 | 0 |
| `hcaptcha-spoof.js` | 606,240 | 2,359 | **802** |
| `trustdevice.js` | 507 | 27 | 0 |
| `trustdevice-botd.js` | 1,058 | 39 | 1 |

`castle.js` 和 `hcaptcha-spoof.js` 是**背靠背**的：castle 结束于
`initializeCastle("pk_xPQ5kRvjnzuTy24zZtig3eNMzspdJS92");`，紧接着就是 spoof 的注释块。

`trustdevice.js` 和 `trustdevice-botd.js` **各有一个 `async function gen()`**，
一个用 `window._fmOpt`，一个用 `window._TDBotD`——**同名函数、不同 API，互换也能编译**。

### 原版作者的注释

`castle.js` 末尾：

```js
initializeCastle("pk_xPQ5kRvjnzuTy24zZtig3eNMzspdJS92");
// Generated by generate-spoof.py from session-20260827-092142; device tables re-captured from
// session-20261029-102720 (iOS 27.0.1 / CriOS 156) and transplanted -- do not hand-edit them.
// Regenerate after every device capture; hand-edits are lost and drift is how the last one died.
```

**这是工艺链的完整说明**：

- 有一个 **`generate-spoof.py`** 生成器
- 设备表来自**两次真机抓取**（`20260827-092142` 和 `20261029-102720`）
- 第二次是 **iOS 27.0.1 / CriOS 156**
- **「do not hand-edit them」+「hand-edits are lost and drift is how the last one died」** ——
  作者自己踩过「手工改设备表导致漂移」的坑

`hcaptcha-spoof.js` 开头：

```js
// The same file is injected into the page and into hsw's worker. A worker has no window,
// no document and no DOM constructors, so every section is feature-gated -- an unguarded
// reference throws on the first line and leaves the worker completely unspoofed, which is
// the single largest surface there is.
```

**这一句说清了最容易被忽略的检测面**：hCaptcha 的 **wasm 跑在 Web Worker 里**，
如果伪造脚本在 worker 里第一行就抛异常，**整个 worker 保持原样**，而那才是最大的检测面。

以及 `WINDOW_BASELINE` 的用途：

```js
// Every own name the engine reported for this window once this script had finished installing --
// document-start, before any page script. Assigned on the LAST line of the file.
let WINDOW_BASELINE = null;
```

**伪造脚本记录「安装完成时 window 上有哪些属性」，之后引擎看到的任何多出来的属性都是页面自己加的。**

### 十条测试

| 测试 | 挡什么 |
|---|---|
| `AllFourteenAreEmbedded` | 资源数 = 14 |
| `EachPageLoadsTheVendorItsNameClaims`（10 个 Theory 用例） | 每个页面真的加载它名字说的厂商 |
| `CaptchaAndEnterpriseUseDifferentScripts` | `api.js` vs `enterprise.js`，两页相邻易混 |
| `GeetestV4UsesTheV4ScriptAndGeetestDoesNot` | `gt4.js` 只在 v4 里 |
| `CastleScriptCarriesItsPublishableKey` | `initializeCastle("pk_…")` 存在 |
| `HcaptchaSpoofIsTheHandWrittenOne` | **注释行 > 700**（压缩库过不了） |
| `TrustDeviceScriptsAreTheTwoSigners` | `_fmOpt` / `_TDBotD` 不互换 |

**`HcaptchaSpoofIsTheHandWrittenOne` 是最强的一条**：它不检查大小或名字，
而检查「**这文件有 34% 的注释行**」——一个压缩过的第三方库不可能满足。
