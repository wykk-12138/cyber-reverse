### 那份没人写下来的依赖链

```
#3 的解锁条件 = 「目标动作的行为证据」= 依赖 #2
#2 的结论     = 静态侧无已知路径（七条路线否证）
────────────────────────────────────────────
#3 因此也是静态侧无已知路径 —— 而它自己的结论「可做数为零」正好与此一致
```

**这条链此前没有出现在任何地方。** 读到 #3 的人只会看到「依赖 #2」，然后去翻 #2；
而 #2 的七条路线写在 `APP_LAYER_BOUNDARY.md` 里，两份文档之间没有指针。

**这与 R650 记的是同一件事**：一次否证是失败，把否证**接起来**才是边界。
