────────────────────────────────────────
这份 prompt 里没有现状
────────────────────────────────────────

它是长期循环的推进规则，只含不变量：目标、优先级、循环、判据、纪律、指针。
**不写任何会过期的事实**（进度数字、已完成清单、待办清单、"某轮已查过"）。

理由：把现状写进来，它下一轮就是错的，而循环还在照它执行；
它还会和"数字只有一个来源"打架，并诱导后续轮次跳过取证。

**每轮开始，现状从这三处读，不从这份 prompt 推断：**
- 数字：docs\METRICS.md（由 python tools\metrics_report.py 生成，唯一来源）
- 未结案项与已知障碍：replica\docs\BINDING_BACKLOG.md、docs\BLOCKERS.md
- 交接与上一轮结论：docs\HANDOFF.md（末尾的"交班快照"）、replica\docs\VERDICT.md（最新一轮）

────────────────────────────────────────
IDA 每次打开的固定例程（按条件判断，不按记忆）
────────────────────────────────────────

IDA 每次启动，GUI 上会弹确认框；**不点掉，插件不会起，13337 不会监听**。
**判据是"再读一次没有任何对话框"，不是"点了 N 次就完"。**

1) 启动（带库路径，后台跑，开库要几分钟）：
   powershell -NoProfile -ExecutionPolicy Bypass -File "D:\projects\vm2api\.dsh\scripts\ida-mcp-doctor.ps1" -Path "<目标 .i64>"

2) 同时用 CUA 轮询点框（不要只等 doctor 的 180 秒超时）：
   mcp__cua__list_windows(app:"ida")
   → 标题为「请确认」/ 询问类的窗口 → mcp__cua__get_window_state 读它 → 按下面的条件选按钮 click
   → **再 list_windows，再读，再点**，直到读不到对话框。

3) 按钮按**条件**选（遇到再判，不要预设）：
   - 「IDA has found an unpacked version of database … It appears IDA did not close properly」
     → 选 **Proceed with unpacked base**。
     理由：磁盘上那份是最近一次实际分析的结果；退回 packed 会丢掉之后新建的符号与注释。
   - 「Database for file '<...>.id0' is not closed. Do you want IDA to repair it?」
     → 选 **是(Y)**。
   - 标题是「请稍候…」的窗口 = 进度条，**等，不要点**。
   - 出现没见过的框：读它的正文再判，**判完把这条规则补进本节**——本节就是用来累积这类规则的地方。

4) 清干净后确认就绪（两条都要过）：
   - doctor 输出 VERDICT: ready
   - mcp__ida__server_health 返回 status: ok，且带 idb_path / hexrays_ready

5) 若 doctor 报 PROXY: MISSING 或端口 REFUSED 且点完框仍在：
   **这是要停下来等 YG 的两类事之一**——告诉 YG「ida 的 MCP 条目请关一次再开」，
   不要重装、不要改 YAML。

────────────────────────────────────────
证据纪律（违反即结论作废）
────────────────────────────────────────

Observation 只能来自工具引用的证据；推理标 Inference + 置信度 + 备择解释。
覆盖不全 / 能力不支持 / 证据冲突一律显式 Unknown，并写清缺哪类证据。
绝不把"证据不全导致的缺席"当成"行为不存在"或"行为等价"。
结构对等 ≠ 行为对等：只能证明属性存在的成员，行为必须记 Unknown。

两条口径（踩过）：
- 存在性/子串扫描只当地图，不当判据；"字符串在源码里"也不等于"那一行被渲染或被调用"。
- 复刻件自己写出的 settings / tasks / solvers / checkoutHistory **不得当实机证据**（循环论证）。
- %APPDATA%\Cybersole 与 %LOCALAPPDATA%\Cybersole **只读**。

活窗口可用时优先用它消歧，但注意：%LOCALAPPDATA% 里跑的是**另一个小版本**，不是对等目标 target\Cybersole.exe；
**每条活窗口观测都要标注观测对象**，并把它与对等目标的关系写成 Inference，不要写成等价。

d) claim 表每条都有 authority（tool-evidence / manual-from-command / unknown）+ 命令 + gap_reason；

   未覆盖的每条写明为什么未覆盖（可做 / 结构差异 / 不可得）。
