# GUI 几何账本（唯一权威表）

这张表是**唯一**记录"原版窗口上量到的数字"的地方。R217 起，所有尺寸都必须来自测量，不许估值。
新增或修改任何一个尺寸，三处要同时改：这张表、代码里那个常量（旁边写明测量方法）、`GeometryLedgerTests`。

## 方法（两种，都要求"两个样本"才算结论）

1. **窗口矩形枚举**：进程启动后每 80–90 ms 枚举它的顶层窗口（`EnumWindows` + `GetWindowRect`），
   用于窗口尺寸、位置、寿命、以及"启动时就建好但隐藏"的窗口。
2. **控件边界像素测量**：同一页面在两个不同窗口宽度下截屏，读表头文字/卡片边缘的 x 坐标，
   相邻差即列宽，归一化后**两个宽度必须给出同一组比例**，否则它不是比例而是别的效应。
