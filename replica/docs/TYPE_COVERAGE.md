## 三、边界

- **只比属性名，不比类型**：镜像的元数据里没有属性的 CLR 类型，所以 `Balance` 是 `double` 还是 `string` 本表不问。
- **只比属性，不比行为**：属性齐了不等于行为等 —— 那要到方法级，而 R1045 说产物无符号，方法级要另找路径。
- **元数据可能不全**：若某属性的 getter 被内联掉，它可能不出现在这个形状里，
  那样「镜像属性数」就是**下界**而不是全量。
