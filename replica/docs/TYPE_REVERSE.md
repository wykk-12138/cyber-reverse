## 边界

- **只比成员名，不比类型与行为**：属性齐了不等于行为等。
- **成员提取是启发式**：复刻件侧用正则抓 `public ... Name { get` 与 `public ... Name(`，
  所以带属性的字段、显式接口实现、以及只读表达式体会漏。**那些漏项会让缺口数偏大，不会偏小。**
- **原版侧可能不全**：若某属性 getter 被内联，它不出现在这个形状里 ⇒ 原版成员数是**下界**。
